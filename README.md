# java-shareit
Это онлайн‑сервис для шеринга (совместного использования) вещей между пользователями.
___

## Описание
- Цель проекта

Предоставить удобную платформу, где:

владельцы могут размещать объявления о доступных для аренды вещахж;

арендаторы могут находить нужные предметы, бронировать их на конкретные даты и оставлять отзывы после использования;

пользователи могут оставлять запросы на вещи, которых пока нет в сервисе, а другие участники — предлагать свои предметы в ответ на эти запросы.

- Целевая аудитория 

Польхователи которые:

хотят сэкономить на покупке редко используемых вещей;

готовы делиться своими вещами и получать выгоду или благодарность за помощь;

ищут нестандартные предметы для разового использования; 

- Контекст разработки

Учебно‑практический проект ShareIt разрабатывается по методологии спринтовой разработки (Agile) для отработки навыков backend‑разработки на Java.

Ключевые технологии: Spring Boot, Hibernate, JPA, PostgreSQL, Maven (многомодульная структура), микросервисная архитектура (shareIt‑server и shareIt‑gateway), REST, юнит‑ и интеграционные тесты.

Этапы разработки:

Спринт 1. Каркас приложения: контроллеры, DTO, мапперы.

Спринт 2. Подключение БД, функционал бронирования и отзывов.

Спринт 3. Запросы на вещи, разделение на микросервисы, валидация в шлюзе, тестирование.

Особенности, приближающие к реальной разработке:

оптимизация под рост нагрузки (шлюз gateway для валидации и кэширования);

проектирование с учётом масштабируемости (разделение ответственности между модулями, изоляция валидации от бизнес‑логики, возможность горизонтального масштабирования gateway).

- Уникальность

Эволюция архитектуры — от монолита к микросервисам (server и gateway) с REST‑взаимодействием.

Задача оптимизации — вынесение валидации в отдельный шлюз для обработки некорректных запросов и масштабирования без перестройки системы.

Работа с многомодульной структурой Maven — настройка зависимостей.

Полный стек Spring‑технологий (REST API, сервисы, репозитории, JPA, DTO, мапперы).

Практика API‑интеграции — создание HTTP‑клиентов, обмен данными в JSON, обработка ответов и ошибок.

Использование промышленных инструментов (Postman, Docker).

## Технологии и инструменты

- **Язык:** Java 17.
- **Сборка:** Maven.
- **Фреймворки:** Spring Boot, Spring Web, Spring Data JPA, Spring Actuator, Spring Validation.
- **БД:** PostgreSQL (продакшн), H2 (тестирование).
- **HTTP‑клиент:** Apache HttpClient 5.
- **ORM:** Hibernate (в составе Spring Data JPA).
- **Прочее:**  MapStruct, Lombok, Hibernate Validator, Jakarta Validation API, Spring Boot Starter JSON,  JUnit, Mockito, Spring Test, Checkstyle, REST API, Postman, SLF4J.

## Установка и запуск

### Требования

- Git.
- Docker.

### Инструкция по установке и запуску через Docker Compose

#### 1. Клонирование репозитория

1. Откройте терминал/командную строку.

2. Перейдите в папку, где хотите разместить проект.

3. Выполните команду:
```bash
git clone https://github.com/AlekseySeledtcov/java-shareit.git
```
4. Перейдите в директорию проекта:

```bash
cd java-shareit
```
#### 2. Сборка проекта

Запустите сервисы через Docker Compose:
```bash
docker-compose up --build
```
#### 3. Проверьте работоспособность

Откройте в браузере

для gateway:
```http
http://localhost:8080/actuator/health
```
для server:
```http
http://localhost:9090/actuator/health
```

Вы должны увидеть ответ: {"status":"UP"}


## В приложении реализованы следующие функции: 
#### Пользователи 
    POST/users - добавлени пользователя 

    PATCH/users/{userId} - обновление полей пользователя
параметры: 
userId - id пользователя

    GET/users/{userId} - получение пользователя по id
параметры:
userId - id пользователя

    DELETE/users/{userId} - удаление пользователя по id
параметры:
userId - id пользователя

    GET/users - получение списка пользователей 

#### Вещи
    POST/items - добавление вещи пользователя с userId
параметры:
X-Sharer-User-Id - userId пользователя

    PATCH/items/{itemId} - обновление полей вещи с itemId пользователя с userId
параметры:
itemId - id вещи
X-Sharer-User-Id - userId пользователя

    GET/items/{itemId} - получение вещи с itemId пользователя userId
Получение вещи со списком комментариев и в случае если запрос отправил хозяин вещи, в ответе заполняются поля с последней и следующей датами бронирования.
параметры:
itemId - id вещи
X-Sharer-User-Id - userId пользователя

    GET/items - получение списка вещей пользователя userId
Получение списка вещей с комментариями и в случае если запрос отправил хозяин вещи, в ответе заполняются поля с последней и следующей датами бронирования.
параметры:
X-Sharer-User-Id - userId пользователя

GET/items/search - поиск вещи по переменной строки запроса
параметры:
text - строка запроса

    POST/{itemId}/comment - добавление коментария вещи с itemId
Добавление коментария вещи с itemId, при условии что пользователь брал эту вещь в аренду ранее.
параметры:
itemId - id вещи

#### Бронирование
    POST/bookings - Добавление бронирования 
параметры:
X-Sharer-User-Id - userId пользователя

    PATCH/bookings/{bookingId} - подтверждение или отклонение бронирования хозяином вещи
параметры:
X-Sharer-User-Id - userId пользователя
bookingId - id брони
approved - переменная строки запроса, принимает значение Boolean

    GET/bookings/{bookingId} - полученние данных боронирования по bookinfId
параметры:
X-Sharer-User-Id - userId пользователя
bookingId - id брони

    GET/bookings/ - получение списка бронирования пользователя userId с фильтром по статусу бронирования и отсортированы по дате
параметры:
X-Sharer-User-Id - userId пользователя
state - принимает значение String (ALL, CURRENT, PAST, FUTURE, WAITING, REJECTED)     

    GET/bookings/owner - получение списка броней для всех вещей текущего пользоватлея, с фильтром по параметру state
параметры:
X-Sharer-User-Id - userId пользователя
state - принимает значение String (ALL, CURRENT, PAST, FUTURE, WAITING, REJECTED)
